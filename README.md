# E-commerce Sales Analysis & Customer Insights

## Project Overview
This project analyzes e-commerce sales data using Python to explore sales performance, customer behaviour, product categories, payment methods, returns, ratings, and delivery performance.

## Objectives
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Analyze sales and customer-related patterns.
- Create visualizations to communicate insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Data Cleaning
- Handled missing values.
- Removed duplicate records.
- Standardized text columns.
- Converted date columns into appropriate data types.

## Project File
- `Project.ipynb` — Jupyter Notebook containing the analysis and Python code.

## Key Learnings
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Extracting insights from data
